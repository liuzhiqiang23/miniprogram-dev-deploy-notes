# 阶段六：备案实录——域名备案 ≠ 小程序备案

## 先分清两件事

| | 给谁备案 | 在哪办 | 需要什么 |
|---|---|---|---|
| **域名（ICP）备案** | 一个**网址**，如 `api.example.cn` | 云服务商的备案系统（腾讯云/阿里云） | 大陆服务器 + 域名 + 主体材料 + **电话核验 + 短信核验** |
| **小程序备案** | **小程序本身** | 小程序管理后台 | 身份证原件拍照 + 人脸识别 |

两者都是工信部的硬性要求，**互不替代，都要做**。

## 域名备案的流程与时间

```
① 提交初审 → ② 云服务商审核 → ③ 提交管局 → ④ 工信部短信核验 → 通过
```

- ② 云服务商审核：**1–2 个工作日**，期间会打 `010` 开头的核验电话
- ③ 管局审核：**1–20 个工作日**，实际多为 1–2 周，这一段是全程最慢且催不动的
- ④ 短信核验：**24 小时内必须回复**，不回直接驳回

## ⚠️ 最容易翻车的两个点

### 1. 审核电话接不到 = 驳回

> 第一次未接通 1 小时内将再次拨打，均未接通将导致驳回，审核电话不支持回拨。

**解法**：把公告里列的那几个 `010-5610-*` 号码存进通讯录，**关掉手机的骚扰拦截**。
很多人是死在拦截功能上的。

### 2. 「网站备注」写不清楚 = 驳回

我们实际收到的驳回理由：

> 个人网站备案备注应写明网站性质（如个人博客）、主要内容（如技术笔记/生活随笔等）、
> 用途（非经营性分享），并声明不发布违法违规内容。

**这是最常见的驳回，改一句话重新提交就行，不是否决。** 模板：

> 本网站为个人非经营性网站，用于分享个人编程技术与数据分析的学习笔记和实践记录，
> 不涉及任何经营性活动，不发布违法违规内容，严格遵守相关法律法规。

**千万别写「影视 / 视频 / 电影」**——备案材料里出现这些字样，管局很可能追问
《信息网络传播视听节目许可证》，个人根本办不下来，那才是真的卡死。

同一批要一起检查的还有**网站名称**：名称和备注是配套看的，
名称里带"电影/票务/传媒"也会被弹，换成「个人技术笔记」这类。

## 腾讯云对未备案域名的拦截

域名没备案但解析到了腾讯云大陆服务器上，HTTP 请求会在**网络层**被劫持：

```
$ curl -I http://www.example.cn/
HTTP/1.1 302
Location: https://dnspod.qcloud.com/static/webblock.html?d=www.example.cn
```

打开就是那张「网站暂时无法访问 / 您的网站未完成备案」的页面。

**这意味着：备案没下来之前，域名无论如何都打不开，跟服务器上 nginx 开不开没关系。**
所以这中间不存在任何"先凑合用"的空间，只能等。

## 小程序备案

入口：小程序后台首页 → 「备案与认证」→ 小程序备案。

- 只需要**本人身份证原件拍照**（人像面 + 国徽面）+ 人脸识别，免费
- 拍照要求：≤2M、分辨率 ≥720×1280、**纸质原件拍摄**、四个圆角完整、
  水印加在空白处且注明用途
- 官方说明是「**在小程序上架发布前完成即可**」——也就是说体验版阶段不强制，
  但早晚要做，可以和域名备案并行

## 微信认证（另一个东西，别搞混）

| | 微信认证 | 小程序备案 |
|---|---|---|
| 收费 | **300 元/年** | 免费 |
| 作用 | 「被搜索」「被分享」能力、认证标识 | 合规要求 |
| 不做的后果 | 不能被搜索/转发，**但可以正常发布** | 不能正式上架 |

如果是课程演示，认证可以不做；想让它像个正经产品能被搜到、能被转发，再花这个钱。
