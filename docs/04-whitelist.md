# 阶段四：体验版与「请求合法域名」的硬门槛

## 现象

代码上传成功、也设成体验版了，同学扫码打开却报：

```
request:fail invalid url
```

而我们自己手机上的开发版/预览版一切正常。

## 原因

微信对网络请求的域名白名单有三条**硬性要求**：

1. 必须是 **HTTPS**（HTTP 不行）
2. **不能是 IP 地址**，也不能是 localhost
3. **域名必须经过 ICP 备案**

关键是：开发者工具里勾的「不校验合法域名」**只对开发版和预览版有效**。
**体验版、正式版必查**，线上没有豁免。

这就是为什么：

| 方案 | 浏览器 | 自己手机（开发/预览版） | 同学（体验版） |
|---|---|---|---|
| 内网穿透（Cloudflare 免费隧道） | ✅ | ✅ | ❌ 域名没备案 |
| 服务器裸 IP | ✅ | ✅ | ❌ 白名单不收 IP |
| 备案过的域名 + HTTPS | ✅ | ✅ | ✅ |

## 怎么配

小程序后台 → **开发 → 开发管理 → 开发设置 → 服务器域名 → 修改** →
在「request 合法域名」里填 `https://api.example.cn`。

注意格式：

- 必须带 `https://`
- 不能带路径、不能带文件名、结尾不要斜杠
- 默认 443 端口，不用写端口号
- 保存时要管理员扫码确认
- **每月修改次数有限**，别乱试

微信在这一步会校验备案。但实测发现它**并不实时校验域名是否能解析**——
所以我们曾在域名还没有 DNS 记录时就把它加了进去（后来腾讯云的拦截页证明，没备案的域名
在网络层就会被劫持，见[阶段六](06-icp.md)）。

## 加体验成员

体验版二维码**只有项目成员和体验成员能打开**，其他人扫码报「暂无体验权限」。

路径：**管理 → 成员管理 → 体验成员 → 添加**，输入对方的**微信号**（不是昵称）。

个人主体的体验成员名额有限，加第一个的时候界面会显示剩余额度。
