# 阶段三：注册正式小程序

## 测试号的局限

微信测试号（AppID 形如 `wx` 开头的测试号）上手最快，但有三个致命限制：

1. **没有成员管理**——后台翻遍了也找不到「体验成员」入口，别人扫码直接报「暂无体验权限」
2. 不能发布
3. 不能配置「请求合法域名」

所以要让**别人**用，必须注册正式小程序。

## 注册

- 入口：`mp.weixin.qq.com` → 立即注册 → 小程序
- 主体类型选「个人」，需要身份证 + 本人微信扫码验证
- 免费，半小时左右走完

## 注册后必做的三件事

### 1. 换 AppID / AppSecret

`project.config.json` 里的 `appid` 换成新的。
后端的 `application.yml` 改成**环境变量占位符**，不要写死：

```yaml
system:
  wx:
    appid:  ${WX_APPID:}
    secret: ${WX_SECRET:}
    # 管理员白名单（微信 openid，逗号分隔），环境变量：WX_ADMIN_OPEN_IDS
    admin-open-ids: ${WX_ADMIN_OPEN_IDS:}
```

**注意：换了 AppID 之后 openid 会变**，之前配的管理员白名单全部作废，
要用新号重新登录一次拿到新 openid，再写回 `WX_ADMIN_OPEN_IDS`。

### 2. 名称审核——纯通用词必被拒

| 试过的名称 | 结果 |
|---|---|
| 电影票务演示 | ❌ 被拒：「以通用词命名」 |
| 影片浏览展示 | ⚠️ 红字警告：需提供商标注册证等材料 |
| **阿强观影** | ✅ 通过（自造词打头 + 业务词收尾） |

**规律：名称必须有"显著识别性"。** 一个自造的前缀（人名、昵称、造的词）+ 一个业务词，
就能过。想沿用行业词，就得拿出商标注册证。

> 修改名称的次数有限（未发布前只有 2 次），提交前想好。

### 3. 头像 / 简介 / 类目

- 头像：144×144 PNG
- 简介：写清楚是「学习交流 / 课程演示」，别碰经营性表述
- 类目：**个人主体选「工具 → 效率」或「工具 → 信息查询」最稳**。
  千万别选「娱乐 / 影音 / 视频 / 文娱」——那些要《信息网络传播视听节目许可证》，个人办不下来

## 凭证管理

| 凭证 | 放哪 | 绝不放哪 |
|---|---|---|
| `WX_APPID` | systemd `EnvironmentFile`（chmod 600） | application.yml 默认值、git |
| `WX_SECRET` | 同上 | 同上 |
| `WX_ADMIN_OPEN_IDS` | 同上 | 同上 |

AppSecret 是「服务器的身份凭证」不是「账号的身份凭证」——
它能调微信接口，但**进不了小程序管理后台**（后台必须管理员本人扫码）。
泄露了也不致命：后台一键「重置」即可作废，记得同步改服务器配置。
